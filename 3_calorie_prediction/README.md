# Проект "Предсказание калорийности блюд"

## Данные
Использован датасет блюд, содержащий:
- изображения блюд
- текстовое описание ингредиентов
- дополнительные числовые признаки:
  - масса блюда
  - количество ингредиентов

Структура данных:
- train — обучающая выборка
- test — тестовая выборка

Перед обучением была выполнена предобработка данных:

Изображения:
- изменение размера до входного размера модели
- нормализация (mean/std из pretrained модели)
- аугментации (для train):
  - случайные кропы
  - повороты и аффинные преобразования
  - горизонтальные отражения
  - изменение яркости и контраста

Текст:
- токенизация с помощью Transformer-токенизатора
- обрезка и паддинг до фиксированной длины

Числовые признаки:
- используются как дополнительные входы без сложной предобработки

## Задача
Построить мультимодальную модель, способную предсказывать калорийность блюда.

Задача формализована как **задача регрессии**.
На вход модели подаются:
- изображение блюда
- текст ингредиентов
- числовые признаки

На выходе модель предсказывает **калорийность блюда**.

Целевая метрика качества — **MAE (Mean Absolute Error)**.

## Описание работы
В рамках проекта реализован полный пайплайн мультимодального обучения.

Основные этапы:
- подготовлен Dataset и DataLoader для мультимодальных данных
- реализована токенизация текстов и батчинг
- реализованы аугментации изображений (Albumentations)
- построена мультимодальная модель:
  - текстовая часть — Transformer (BERT)
  - визуальная часть — CNN (EfficientNet)
  - числовые признаки — MLP
- выполнено объединение признаков из разных модальностей
- реализован регрессионный head
- реализована гибкая настройка обучения через конфиг
- добавлена возможность частичного размораживания слоев
- реализован training loop и валидация
- реализовано сохранение лучшей модели
- добавлено логирование истории обучения

## Результаты
В ходе экспериментов была обучена мультимодальная модель, объединяющая:
- текстовые признаки
- визуальные признаки
- дополнительные числовые признаки

Модель показала, что:
- использование изображений и текста вместе даёт лучшее качество, чем каждая модальность по отдельности
- дополнительные числовые признаки (масса, количество ингредиентов) улучшают точность
- transfer learning (предобученные модели) существенно ускоряет обучение и повышает качество
