# Проект "Классификатор таблеток"

## Данные
Использован датасет изображений таблеток OgyeiV2.
Данные представлены в виде изображений, сгруппированных по классам (каждый класс соответствует определённому типу таблетки).

Структура датасета:
- train — обучающая выборка
- test — тестовая выборка

Перед обучением была выполнена базовая предобработка изображений:
- изменение размера изображений до 224×224
- преобразование в тензоры
- нормализация значений пикселей

## Задача
Построить модель компьютерного зрения, способную классифицировать изображения таблеток по их типу.

Задача формализована как задача **многоклассовой классификации изображений**.  
На вход модели подаётся изображение таблетки, на выходе модель предсказывает один из возможных классов.

Целевой метрикой качества является **accuracy**.

## Описание работы
В рамках проекта был реализован полный пайплайн обучения модели компьютерного зрения.

Основные этапы работы:
- исследована структура датасета и количество классов
- реализована загрузка изображений с помощью `ImageFolder`
- подготовлены `Dataset` и `DataLoader` для обучения
- реализованы функции обучения и оценки качества модели
- обучена собственная сверточная нейронная сеть (baseline)
- обучены предобученные модели **MobileNetV2** и **EfficientNet-B0**
- выполнен transfer learning с заменой классификационного слоя
- проведена оценка качества на валидационной выборке
- построена **confusion matrix**
- выполнен анализ наиболее частых ошибок классификации
- визуализированы примеры изображений для ошибочных классов
- проведено сравнение моделей по качеству

## Результаты
В ходе экспериментов было обучено несколько моделей.

Наилучший результат показала модель **EfficientNet-B0**, которая достигла accuracy около **88%** на валидационной выборке.

Более высокое качество данной модели объясняется:
- использованием предобученных весов ImageNet
- более эффективной архитектурой сети
- лучшей способностью извлекать визуальные признаки из изображений

Модель EfficientNet показала более высокую точность по сравнению с собственной CNN и MobileNet.
