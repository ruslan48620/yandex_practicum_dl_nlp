# Репозиторий для учебных проектов Яндекс.Практикума

Данные проекты были выполнены в ходе обучения в Яндекс.Практикуме, по курсу "Инженер по глубокому обучению нейросетей: обработка естественного языка"

| № | Название проекта | Описание |
| :---------------------- | :---------------------- | :---------------------- |
| 1 | [Автодополнение текстов](text-autocomplete) | Реализовать систему автодополнения текста, которая по префиксу предсказывает продолжение. |
| 2 | [Классификатор таблеток](2_meds_classification) | Построить модель компьютерного зрения, способную классифицировать изображения таблеток по их типу. |
| 3 | [Предсказание калорийности блюд](3_calorie_prediction) | Построить мультимодальную модель, которая будет предсказывать калорийность блюд по фотографиям и текстовому описанию их ингредиентного состава. |
